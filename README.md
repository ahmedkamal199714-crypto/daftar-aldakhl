# دفتر الدخل

تطبيق ويب لإدارة دفتر التحويلات اليومية بين أحمد وسامح — نفس صفحات وأسلوب الدفتر الأصلي.

## الصفحات
- **الرئيسية** — الأرصدة (أحمد / سامح / الإيجار / الخاص بسامح / النقدية) + إجراءات سريعة + آخر الحركات
- **الحركات** — كل التحويلات والمصروفات مع فلترة حسب النوع وتعديل/حذف
- **كشف الحساب** — كشف لكل طرف (يومي / شهري / فترة / الكل) مع الرصيد المتحرك، وطباعة PDF
- **التقارير** — ملخص التحويلات والمصروفات وتوزيعها
- **رأس المال** — إيداعات وسحوبات رأس المال منفصلة عن أرباح الدفتر
- **سجل التدقيق** — كل إضافة وتعديل وحذف
- **الإدارة** — دعوة شريك (عرض فقط)، نسخة Excel / JSON احتياطية واستعادتها

## القسمة الثابتة للتحويل
إيجار 130 + سامح 300 + خاص 100، والباقي يضاف لرصيد أحمد تلقائياً.
النقدية = مجموع الأرصدة الأربعة.

## التقنية
- ملفات ثابتة بدون أي خطوة بناء: `index.html` + `css/styles.css` + `js/app.js`
- تسجيل الدخول بحساب جوجل عبر Firebase، والبيانات في Firestore (المجاني)
- النشر على GitHub Pages من فرع `main`
- حتى يتم ربط إعدادات Firebase في `js/firebase-config.js` يعمل التطبيق في وضع محلي (يحفظ في المتصفح فقط)

## التعديل
كل المحتوى عربي RTL بخط IBM Plex Sans Arabic. عدّل أي ملف وارفعه على نفس الفرع وسيتحدث الموقع تلقائياً خلال دقيقة.
